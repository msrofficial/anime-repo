# MSR Anime Extensions Repo

This branch hosts the published Aniyomi/Anikku extension repository for MSR sources.

## Repo URL

Add this URL in Aniyomi/Anikku:

```text
https://raw.githubusercontent.com/msrofficial/anime-repo/repo/index.min.json
```

## Available Extensions

| Extension | APK |
| --- | --- |
| Toonstream | `apk/aniyomi-hi.toonstream-v14.5.apk` |
| AnimeDubHindi | `apk/aniyomi-hi.animedubhindi-v14.4.apk` |
| MovieBox | `apk/aniyomi-hi.moviebox-v14.6.apk` |

## Files

- `index.min.json`: extension index consumed by Aniyomi/Anikku.
- `repo.json`: repository metadata and signing fingerprint.
- `apk/`: signed release APKs.
- `icon/`: extension icons.

## Source Code

Source code and build workflow live here:

[https://github.com/msrofficial/anime-extensions](https://github.com/msrofficial/anime-extensions)

Do not edit APK/index files manually. They are generated from the source repository by GitHub Actions.
